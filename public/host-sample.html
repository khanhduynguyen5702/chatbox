Sample Host Page

This page demonstrates how to embed the test chat widget. The snippet below will inject a floating launcher that opens the widget iframe.

Embed snippet (copy & paste into your page):

<script src="/widget-loader.js"></script>

When running the dev server, open this page at /host-sample.html to try it.

Note: For cross-origin embedding in production you should host a widget endpoint and use a fully qualified URL in the loader (not /widget.html), and consider using a sandboxed iframe or postMessage authorization.
